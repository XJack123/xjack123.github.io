# Jack — Personal Website

A minimal bilingual space for research, projects, outdoor life, and learning notes.

**[Visit the website →](https://xjack123.github.io/)**

`HTML` · `CSS` · `JavaScript` · `GitHub Pages`

## Sections

- **About** — background, research and interests.
- **Projects** — research and things built along the way.
- **Life** — hiking, skiing, and everyday moments.
- **Notes** — things learned and questions worth keeping.

The homepage stays focused on a personal introduction and links into each section. Chinese and English versions share the same site.

## Run locally

```bash
python3 -m http.server 8000
```

Open http://127.0.0.1:8000. This serves the public site only.

## Content and publishing

Public content lives in `site-data.js`. GitHub Pages serves this repository.

The owner uses a separate local editor to save drafts and publish content updates. That editor, private notes, backups and GitHub credentials do not belong in this public repository. The former public admin page has been removed.
